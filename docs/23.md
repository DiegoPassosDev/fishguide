# Arquitetura DevOps e Infraestrutura

- **Projeto:** FishGuide
- **Versão:** 1.0

## 1. Objetivo

Definir toda a infraestrutura necessária para desenvolver, testar, implantar e operar o FishGuide de forma segura, escalável e confiável.

## 2. Princípios

Toda a infraestrutura seguirá cinco princípios.

**Simplicidade**

Começar pequeno.

Escalar somente quando necessário.

**Automação**

Tudo que puder ser automatizado deverá ser automatizado.

**Observabilidade**

Todo problema deverá ser facilmente identificado.

**Reprodutibilidade**

Qualquer desenvolvedor deverá conseguir executar o projeto localmente com poucos comandos.

**Escalabilidade**

A arquitetura deverá suportar crescimento sem necessidade de grandes reescritas.

## 23. Minha sugestão para evolução da arquitetura

**Arquitetura Orientada a Eventos**

Hoje teremos um backend monolítico modular, que considero a melhor escolha.

Mas ele já nascerá preparado para eventos.

Exemplo:

- Captura registrada

↓

Evento publicado

↓

Atualizar estatísticas

↓

Atualizar FG Score

↓

Atualizar Memória Coletiva

↓

Enviar notificação

Quando o sistema crescer, alguns módulos poderão ser extraídos para microsserviços sem reescrever toda a aplicação.
