# Arquitetura Front-end

- **Projeto:** FishGuide
- **Versão:** 1.0

## 1. Objetivo

Definir a arquitetura frontend do FishGuide, estabelecendo:

- organização do código; 
- padrões de componentes; 
- experiência do usuário; 
- gerenciamento de estado; 
- comunicação com API; 
- responsividade; 
- Design System. 

## 2. Stack Oficial

**Framework**

Vercel Next.js

Motivos:

- excelente performance; 
- Server Components; 
- SEO; 
- escalabilidade; 
- ecossistema maduro. 

**Linguagem**

TypeScript

Objetivos:

- segurança de tipos; 
- melhor manutenção; 
- menos erros em produção. 

**UI**

Tailwind CSS 

- shadcn/ui 

Radix UI 

Objetivos:

- componentes acessíveis; 
- consistência visual; 
- velocidade de desenvolvimento. 

**Estado**

**Servidor**

TanStack Query

Responsável por:

- cache; 
- sincronização; 
- atualização automática; 
- estados de loading. 

**Estado global**

Zustand

Para:

- preferências; 
- sessão; 
- filtros; 
- configurações. 

**Formulários**

React Hook Form + Zod

Responsável por:

- validação; 
- formulários complexos; 
- mensagens de erro.

- Service Worker;

## 21. Minha sugestão mais importante

**Interface Adaptativa do Pescador**

O FishGuide deverá aprender como cada pessoa utiliza o aplicativo.

Exemplo:

- Pescador A:
- pesca cedo; 
- gosta de robalo; 
- usa isca artificial. 

A tela HOJE prioriza:

- maré da manhã; 
- robalo; 
- condições de artificial. 

Pescador B:

- pesca à noite; 
- prefere praia; 
- usa isca natural. 

A experiência muda.

O aplicativo deixa de ser apenas personalizado.

Ele se torna **individual**.

## 23. Minha maior ideia deste documento

**FishGuide Living Interface**

A interface não será fixa.

Ela muda conforme o contexto.

Exemplos:

- **Em casa:**
- Modo planejamento.
- mapas; 
- histórico; 
- análises. 

**Antes da pescaria:**

- Modo preparação.
- previsão; 
- missão; 
- equipamentos. 

**Durante a pescaria:**

- Modo campo.
- simples; 
- rápido; 
- operacional. 

**Depois:**

- Modo memória.
- registros; 
- aprendizado; 
- compartilhamento. 

A mesma aplicação acompanha todo o ciclo da pescaria.
